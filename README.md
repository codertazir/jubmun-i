# JUBMUN I Prototype

Create a modern, responsive landing page that closely follows the provided reference images.

Hero Section

 Use the attached hero image as the full-width background of the hero section.

 Lower the background image opacity slightly (or add a subtle dark overlay around 20–30%) so the text remains highly readable while the image is still clearly visible.

 The hero section should otherwise match the reference image as closely as possible in terms of:

 Layout

 Typography

 Spacing

 Alignment

 Button styles

 Overall visual hierarchy

Do not include the navigation bar shown in the reference image (such as "Welcome," "Minimum," or any other navigation links). Start directly with the hero content.

 The countdown timer should count down to November 26. It should update automatically in real time and display the remaining days, hours, minutes, and seconds in the same style as the reference image.

Content Below the Hero

 Everything below the hero section should closely replicate the second reference image.

 Match the overall structure, spacing, section order, typography, card styles, colors, and layout while keeping the design fully responsive.

 Preserve the same visual style and user experience shown in the reference.
